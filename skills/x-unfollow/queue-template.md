# Private account review queue — template

Copy outside the public repository AND installed skill folder. Fill account and
profile location privately. Preferences are not action grants. Default mode is
preview, with no approved targets. Use immutable platform IDs when available.

## Setup

- Profile version: 2
- Platform/account: unset
- Timezone: unset
- Confirmed sources and coverage: none
- Keep lanes/protected targets: none confirmed (not proof there are none)
- Mode: preview
- Maximum attempted actions: 10/run, 20/account/day; lower user limits win
- Grants: none

## Approved batch references

Record the private grant ID/version, account, exact target IDs/action, expiry and
user confirmation reference. A `cut` word in this table is not a complete grant.
